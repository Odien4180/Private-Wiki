# Unity Analysis (Planned - Milestone 5)

This document will define Unity project detection and analysis of
`*.meta`, `*.unity`, `*.prefab`, `*.asset`, `*.asmdef`,
`Packages/manifest.json` and `ProjectSettings/*`, including GUID-based
asset reference tracking. Unity serialized data that cannot be parsed
must never be guessed.

Not yet implemented. See `docs/architecture.md` for the milestone plan.
